# Ant-War
Projet de simulation / jeu de stratégie temps réel de colonies de fourmis (Python / Pygame).

[![Démo vidéo Ant War](https://github.com/user-attachments/assets/bb3ceb8d-32de-49ca-a5ba-2f3b06fba08f)](https://www.youtube.com/watch?v=676DJfg7OE8)

## Fonctionnalités
- 6 races aux mécaniques distinctes
- Fourmis autonomes guidées par phéromones
- IA adverses (raids, alarmes, antennation)
- Multijoueur en réseau local (jusqu'à 4 joueurs)

## Lancer le jeu
pip install pygame numpy
python main.py
